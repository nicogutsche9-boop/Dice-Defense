# Dice Defense V10 — Real GLB Asset Edition

Die von dir bereitgestellte 3D-Asset-Sammlung ist direkt in das V9-Projekt integriert.

## Enthalten
- 60 Würfel-GLB-Modelle
- 15 Gegner/Boss-GLB-Modelle
- echte GLB-Vorschau mit Three.js/GLTFLoader
- 3D-Asset-Library mit Würfel/Boss/Alle-Filter
- vorhandene V9-WebGL-Arena
- Online-Koop-Grundlage aus V7

Die Modelle liegen unter `public/assets/dice/` und `public/assets/bosses/`.
Das originale `manifest.json` bleibt enthalten und wird beim Laden als Katalog verwendet.

## Start
```bash
npm install
npm start
```
Danach `http://localhost:8080`.

## Lizenz
Die mitgelieferte Asset-Paket-README bezeichnet die Modelle als CC0-1.0.

## Nächster Schritt
Die echten GLB-Modelle können jetzt als die eigentlichen Würfel/Bosse des Spiels verwendet werden. Danach können wir jedem Modell Stats, Rarität, Animationen, Angriffseffekte, Fusionen, Boss-Phasen und serverseitige Fähigkeiten zuweisen.
